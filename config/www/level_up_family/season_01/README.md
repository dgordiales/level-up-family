# Temporada 1: The Origin

Recursos utilizados por el tema y los paneles. Home Assistant publica esta carpeta en `/local/level_up_family/season_01`.

`banner.png` y `fondo_vertical.png` dan forma al panel. Los iconos representan XP, nivel, misiones, temporada, semana, bonus, rachas y penalizaciones. `emblema.png` completa el conjunto gráfico de la temporada.

Para una temporada nueva, conservar los nombres esperados por las plantillas dentro de una carpeta `season_XX` y añadir su definición de tema mediante un PR. Copiar imágenes no cambia la temporada activa ni reinicia contadores.
